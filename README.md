# VRCompanion

The first download is coming soon.

Voice commands, a pet and live captions for VRChat, on Windows.
Not made by or affiliated with VRChat.

## Getting started

1. Run the installer.
2. Follow the setup: log in to VRChat on VRChat's own page (optional), pick
   your microphone, bring in your favorite avatars and worlds.
3. In VRChat, turn on OSC: Action Menu → Options → OSC → Enabled.
4. Say "computer, hello".

Windows may warn about an unknown publisher the first time: choose "More info",
then "Run anyway".

**[User guides](docs/README.md)**: every command, the pet, the wrist menu,
settings, and what to do when something doesn't work.

This repository only holds the downloads and the guides.
