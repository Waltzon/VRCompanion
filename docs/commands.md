# What you can say

Start every command with the wake word (`computer` unless you changed it), or use
[push-to-talk](voice.md#push-to-talk) and skip it. The app's **What can I say?**
page lists these with your own avatar, world and friend names, and you can
**type** any of them on the Home page.

## Avatars, outfits and toggles

| Say | Does |
| --- | --- |
| switch to **fox** / put on fox / avatar fox | an avatar you gave a name |
| switch to **two** / switch to avi 2 / the second one | the 2nd avatar in your list |
| **surprise me** / random avatar | a random avatar (never the one you're wearing) |
| **turn on glow** / glow on / show tail | an avatar toggle on |
| **ears off** / hide tail | ...off |
| **toggle ears** | flip it |
| **set outfit to 2** / set hue to 50 percent | a number or slider on your avatar |
| **outfit cozy** / put on my cozy outfit | an [outfit](avatars-and-worlds.md#outfits) |
| **outfit 2** | this avatar's outfit 2 (never switches avatar) |
| **switch to avatar 1 outfit 2** / fox outfit 2 | switch avatar, then its outfit 2 |
| **save current look** / save look as cozy | save what you're wearing as an outfit |
| **surprise me with an outfit** / random outfit | a random outfit of this avatar |

## Worlds and places

| Say | Does |
| --- | --- |
| **open black cat** / create new instance black cat | a new instance of that world |
| ...**private** / **friends plus europe** | with a type (`public`, `friends plus`, `friends`, `invite plus`, `invite`/`private`) and region (`us`, `us west`, `us east`, `europe`, `japan`) |
| **take me home** / go home | a new private instance of your home world |
| **rejoin** / go back | the instance you were in before |
| where have I been | your recent worlds |
| **where am I** | the world and instance type you're in |

## Friends and status

| Say | Does |
| --- | --- |
| **invite alex** | invite a friend to your instance |
| **join alex** / take me to alex | go to a friend's instance |
| **request invite from alex** | ask a friend for an invite |
| **invite the squad** | everyone in a [friend group](friends.md#groups) who's online |
| **who's online** / **where's alex** | shown only to you |
| **accept** / decline | the newest invite or request |
| **pick someone** | a random friend in your instance |
| set status to **busy** / status join me | your status: `online`, `join me`, `ask me`, `busy` (or green, blue, orange, red) |
| set status to **streaming** | a status preset (Settings → VRChat) |
| clear status message | remove your status text |

## Chat, help and safety

| Say | Does |
| --- | --- |
| **activate chat mode** / stop chat mode | everything you say goes to the chatbox ([chat mode](voice.md#chat-mode)) |
| **undo** / take that back | put back the avatar, status, outfit, toggle or chat mode from before |
| **do that again** | repeat your last command |
| **remember that** | after a miss and a retry: learn how you say it ([details](voice.md#when-it-mishears-you)) |
| **hello** | check it hears you |
| **safe mode** / panic / get me out of here | [safe mode](routines-and-extras.md#safe-mode) |
| **captions on** / translate for me | [live captions](in-vr.md#live-captions) |
| **open menu** / close menu | the [wrist menu](in-vr.md#wrist-menu) in VR |
| **battery** / how's my battery / battery levels | how full your controllers and trackers are ([battery warnings](in-vr.md#battery-warnings)) |

## Routines, timers and fun

| Say | Does |
| --- | --- |
| **bedtime** / run bedtime | one of your [routines](routines-and-extras.md#routines) |
| **set a timer for 10 minutes** | a timer |
| **remind me to drink water in 30 minutes** | a reminder |
| how long left / cancel my timers | check or cancel timers |
| **roll a d20** / roll 2 d6 / flip a coin / pick a number between 1 and 100 | shown to everyone |
| how long have I been in VR | your session time |

## The pet

| Say | Does |
| --- | --- |
| **mochi, sit** / jump / spin / dance / do a trick / sleep / come here | [pet](pet.md) actions |
| **how is mochi** | its mood, headpats and pets met |
| **mochi, switch to fox** | any command: the pet's name works like the wake word |
| **mochi, pat challenge** | 10 seconds of headpats for everyone |
| **mochi, hide** / **play hot and cold** / am I close / I give up | [hide and seek](pet.md#hide-and-seek) |
| **mochi, remember that** alex likes cats | keep a short fact ([memory](pet.md#memory)) |
| **mochi, what do you remember** / what do you know about alex | what it remembers (only shown to you) |
| **mochi, forget about** alex / **forget that** / **forget everything** | forget facts ("undo" brings them back) |

## Anything else

With the [AI brain](ai-brain.md) on, anything that isn't a command above goes to
Claude, which works out what you meant ("put me in something comfy and open a
cozy room").
